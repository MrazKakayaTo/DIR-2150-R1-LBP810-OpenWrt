# Changelog

## v1.0.0-beta — 2026-11-05

- Prepared offline DIR-2150 R1 / OpenWrt 25.12.5 installation bundle.
- Added CUPS 2.3.3, CAPT USB backend, and streaming PWG Raster conversion.
- Successfully printed from Windows 10 using Microsoft IPP Class Driver, with no Canon driver installed on Windows.
- Documented duplicate `cupsd` startup issue and persistent startup links.
- Documented Android test jobs saturating the queue. Mobile printing is not supported yet.
- Preserved tested installer archive and supplied a Russian Word installation guide.

### Planned / not implemented

- Android/AirPrint/Mopria interoperability, DNS-SD/Avahi advertising.
- Better handling and cancellation of stalled jobs.
- Support for additional OpenWrt targets and firmware versions.
